# Diagram and Flowchart Library for Zoology Mains Answers

This library standardizes diagrams and flowcharts for UPSC / State PSC style Zoology answers.

## Core Principle

Diagrams should be:

- Simple
- Fast to draw
- Boxed
- Clearly labelled
- Scientifically accurate
- Useful for scoring marks

The goal is not artistic perfection. The goal is **scientifically complete representation**.

---

## 1. Right-Hand Labelling Rule

Use labels only on the right side whenever possible.

```text
+-----------------------------+
|                             |
|       Simple diagram        |---- Label 1
|       or schematic          |---- Label 2
|                             |---- Label 3
+-----------------------------+
```

Rules:

- Keep pointer lines straight and horizontal.
- Do not cross pointer lines.
- Avoid labels on both sides unless unavoidable.
- Keep labels short and technical.

---

## 2. Split-Screen Page Layout

For handwritten answers, use this mental format:

```text
+----------------------+-------------------------------+
| Diagram / Flowchart  | Descriptive bullet points      |
| Left 40%             | Right 60%                     |
|                      | - Point one                   |
|                      | - Point two                   |
|                      | - Point three                 |
+----------------------+-------------------------------+
```

In Markdown answers, reproduce this by placing the diagram first, then concise bullet points under subheadings.

## 3. High-Yield Diagram Types

### A. Classification Flowchart

Use for taxonomy and evolutionary sequences.

```text
Chordata
   ↓
Protochordata
   ↓
Urochordata + Cephalochordata
   ↓
Vertebrata
```

### B. Evolutionary Sequence

Use for vertebrate evolution.

```text
Protochordates
      ↓
Agnatha
      ↓
Pisces
      ↓
Amphibia
      ↓
Reptilia
      ↓
Aves + Mammalia
```

### C. Structure-Function Diagram

Use for organs or anatomical features.

```text
+-------------------------------+
| Chordate Body Plan            |
|                               |---- Dorsal hollow nerve cord
|                               |---- Notochord
|                               |---- Pharyngeal gill slits
|                               |---- Post-anal tail
+-------------------------------+
```

### D. Comparative Table

Use for short comparisons.

```md
| Feature | Urochordata | Cephalochordata |
|---|---|---|
| Notochord | Larval tail only | Throughout body |
| Adult form | Sessile | Free-living |
| Metamorphosis | Retrogressive | Absent |
```

Note: Telegram does not render tables well, but GitHub Markdown does. Use tables inside repo files where they help.

### E. Life-Cycle Flowchart

Use for larval development and metamorphosis.

```text
Egg
 ↓
Larva
 ↓
Metamorphosis
 ↓
Adult
 ↓
Reproduction
```

### F. Feedback / Physiological Flowchart

Use for hormones or physiological mechanisms.

```text
Stimulus
   ↓
Receptor
   ↓
Control centre
   ↓
Effector
   ↓
Response
```

## 5. Diagram Selection Guide

Use:

- **Classification flowchart** for taxonomic questions.
- **Evolutionary sequence** for origin/evolution questions.
- **Structure-function diagram** for anatomy questions.
- **Comparative table** for differences and affinities.
- **Life-cycle flowchart** for developmental questions.
- **Feedback diagram** for physiology questions.

---

## 6. Diagram Quality Checklist

Every diagram / flowchart should satisfy:

- [ ] Boxed where possible
- [ ] Labels on right side
- [ ] Straight pointer lines
- [ ] No crossed labels
- [ ] Short technical labels
- [ ] Directly relevant to answer
- [ ] Easy to reproduce in exam hall
