# UPPSC GDC Assistant Professor Zoology Mains Question Bank

A structured, unit-wise question-answer bank for the **UPPSC Government Degree College Assistant Professor Zoology Mains Examination**.

## Exam Pattern

### Section A: Short Answer Questions
- 10 questions
- 8 marks each
- Strict answer range: 110–125 words

### Section B: Long Answer Questions
- 10 questions
- 12 marks each
- Strict answer range: 175–200 words

## Content Standard

This repository targets:
- UPPSC GDC Assistant Professor Zoology
- State PSC Assistant Professor Zoology examinations
- UGC NET foundation-level revision
- MSc Zoology university examination preparation

## Workflow

Each unit must be completed sequentially:

1. Extract unit syllabus.
2. Create `research/unit-XX/topic-map.md`.
3. Generate 15–25 important topics.
4. Generate 10 short answer questions with 110–125 word model answers.
5. Generate 10 long answer questions with 175–200 word model answers.
6. Add key terms and source validation for every answer.
7. Run quality audit.
8. Validate Markdown.
9. Commit and push the completed unit.
10. Open a pull request when working from a feature branch.

## Quality Rules

Every answer must include:
- Question
- Model answer
- Key terms
- Source validation

Every unit must include:
- Important topics
- Short answer section
- Long answer section
- Quality audit checklist
